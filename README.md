# BMS Website Redesign – React Project

## Overview
This repository branch contains the React-based implementation of the BMS website redesign.

The goal is to maintain a clean, centralized and up-to-date version of the project that can be accessed, reviewed and extended at any time.

---

## Development Workflow

- All development must take place within this repository
- Do not rely on local-only changes
- Work in this dedicated branch (not on `main`)
- Push updates regularly to ensure the latest state is always available

---

## Instructions

Please upload the **current full project state** to this branch.
This should represent the latest working version of the project.

---

## Project Requirements

Make sure the repository contains everything required to run the project:

- complete source code (`src`)
- public assets (`public`)
- `package.json`
- configuration files
- build setup
- any additional required files

If certain files cannot be included (e.g. environment variables), please document them.
